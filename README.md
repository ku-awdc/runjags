# runjags
An R package implementing interface utilities, model templates, parallel computing methods and additional distributions for MCMC models in JAGS

This package requires JAGS (https://sourceforge.net/projects/mcmc-jags/) at both compile time and run time: compiler flags are obtained directly from the rjags package, which ensures that JAGS is compiled against the same JAGS installation as rjags (and this is re-checked at run time when loading the JAGS extension module contained within runjags). Note that installing a different major version of rjags will require the runjags package to be re-compiled. This version of runjags has a version dependency on rjags_5-5 in order to ensure that pre-compiled versions of rjags and runjags are compatible on CRAN, but in practice runjags 2.3.0 and onwards will compile with either JAGS 4 and rjags_4-18 (after adjusting the DESCRIPTION file) or JAGS 5 and rjags_5-5 or later.
